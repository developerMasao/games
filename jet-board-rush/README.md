# JET BOARD RUSH — FROST RIDGE

ジェット付きボードで雪山を滑り降りる、オートスクロールの横スクロールアクション。
参照は『ロックマン8』のスノーボード面と、スーパーマリオの自動スクロール面。
**1プレイ約55秒。** 依存は CDN の three.js だけで、`index.html` 単体で動きます。
**スマホ（横向き）対応。**

## 遊び方

プレイヤーは勝手に右へ進み続けます。できるのは **跳ぶ・伏せる・減速する** の3つだけ。

| | PC | スマホ |
| --- | --- | --- |
| ジャンプ | `↑` / `W` / `Space`（長く押すほど高い） | 画面右側をタップ（長押しで高く） |
| しゃがみ | `↓` / `S` | 押したまま下へスワイプ |
| 減速（後ろ向き） | `←` / `A` | 画面左端を押し続ける |
| ポーズ / 音 | `ESC` / `M` | 右下の ♪ |

ゲームパッドも使えます（A ボタン=ジャンプ、十字キー下=しゃがみ、左=減速）。

**画面の説明は最小限**です。タイトル画面では AI が自動でコースを走っていて、操作は最初の
8秒（跳ぶしかない柱 → 伏せるしかないアーチ → 跳ぶしかない穴）が教えます。結晶はジャンプの
軌道上に並んでいるので、取ろうとすると自然に正しい跳び方になります。
一度クリアするとヒント表示は出なくなります。

## 設計：ジェットコースターの緩急を借りる

前の版は 88秒で、動作の間隔が最大 6.9秒空いていて「だらっと」していました。
今の版は **55秒・動作40回・間隔の中央値 1.32秒・最大でも 2.3秒**。
コースは **5つの波**でできていて、それぞれが

```
溜め（2秒）  この先の密集地帯が見えている。何も来ない
放出（5秒）  0.9〜1.3秒間隔で連打。ここが見せ場
抜け（2秒）  結晶が並んでいて息を吸える
```

という形をしています。波ごとに主題があります。

| 波 | 主題 |
| --- | --- |
| 導入 | 8秒で3つの操作を教える |
| 波1 | **下って加速** → 飛び石3連 |
| 波2 | くぐり連打（伏せ→伏せ→跳ぶ） |
| 波3 | **氷結ゾーン**。ブレーキが効かないまま密集地帯へ |
| 波4 | **ジャンプ台**。坂を駆け上がって大穴を跳ぶ（この面の見せ場） |
| 波5 | 最高速の総まとめ |

## 地形：坂とジャンプ台

地形は「平ら」だけでなく**傾斜**を持ちます。下り坂では速度が最大 1.42 倍まで伸び、
上り坂では 0.74 倍まで削れます。坂は基準の速度カーブに**一時的に乗る倍率**として効くので、
難易度カーブの設計を壊さずに局所的な緩急だけを足せます。

**上り坂の終端はジャンプ台**になります。坂を離れる瞬間（＋その後 0.32秒）にジャンプすると、
坂の傾きと速度に応じた上向きの勢いが跳躍に上乗せされ、通常の倍近く飛びます。
波4の大穴（12m）はこれを使って跳びます。踏み切り場に平らな部分を作ってあるので、
「どこで跳ぶか」が目で分かります。

速度は進行度の折れ線で決まります（`STAGES[0].speed`）。

| 進行度 | 0% | 30% | 50% | 70% | 100% |
| --- | --- | --- | --- | --- | --- |
| 速度 | 12.0 m/s | 15.5 | 17.0 | 18.5 | 21.5 |

## 体感速度

速度は m/s ではなく画面の流れ方で感じるものなので、速度に連動させています。

- **画角（FOV 34°→41°）とカメラ距離**が速度で広がる
- **手前を小物が流れる**（画面の下端をかすめる氷片）。速度感の大半はこれ
- 高速域で**流線**が走り、雪煙が増え、カメラが微振動する
- **着地でカメラが沈む**（落下速度に比例）
- 風の音程・ジェット音・**BGM のテンポ**（最大 +22%）が速度に連動
- カメラは **20m 先の地形の高さ**を見て構えるので、落ちる前に落ちる先が見える

## ニアミス

障害物を**すれすれ（0.62m 以内）で通過**すると火花が散って +40点。穴の縁ぎりぎりに
着地したときも入ります。危ない通り方が損ではなく得になるので、自分から際どく攻める動機になります。
結晶もアーチの真下や柱の直後といった危ない位置に置いてあります。

## ダメージ（超魔界村方式）

被弾しても即ミスにはなりません。**服が脱げてパンツ一丁**になり、脱げた服が後ろへ飛びます。
パンツ一丁でもう一度当たるとミス。穴に落ちた場合は一発でミスです。
残機表示はありません。**自分の見た目が残りHP**です。1プレイが短いので、ミスしたら最初から。

コース上の赤い上着アイテムを取ると服が戻ります（服がある状態で取ると結晶5個ぶん）。

## コースの作り方（データ構造）

コースは**部品（CHUNK）を並べただけ**です。`CHUNKS` に部品を足して `STAGES[].seq` に
名前を並べれば、新しいコースができます。

地形は `terrain`（**長さと高低差の鎖**）で持ちます。`['gap', 幅, 落差]` が穴です。

```js
w4_launch: {
  len:173,
  //        平ら   上り坂    踏み切り   大穴(先が3m下)  下り     平ら   穴    平ら
  terrain:[[20,0],[16,4.5],[6,0],['gap',12,-3],[22,-2],[24,0],['gap',9],[16,0],[48,0]],
  ents:[
    {t:'low',   x:14, w:4, y:1.30},        // くぐる（地面から 1.30m）
    {t:'block', x:40, h:1.8, w:1.6},       // 跳ぶ（上面には乗れる）
    {t:'plat',  x:20, w:7, y:0.8},         // 飛び石の足場
    {t:'ice',   x:18, w:92},               // 氷結ゾーン
    {t:'enemy', x:72, kind:'slider'},      // slider=地上（跳ぶ）/ flyer=頭の高さ（伏せる）
    {t:'coin',  x:44, y:3.4},              // 大穴の上に置くと飛距離の目印になる
    {t:'coins', x:6, y:0.65, n:3, dx:2.6, arc:1.2},
    {t:'wear',  x:106, y:2.0},             // 服の回復
    {t:'sign',  x:4}, {t:'hint', x:6, icon:'brake'}, {t:'goal', x:30}
  ]}
```

`compile()` がこれを絶対座標のワールドに展開します。`ents` の `y` は**その地点の地面からの高さ**
なので、坂の上でも同じ書き方でいいです（障害物は幅の中で**一番高い地面**を基準に置かれます。
低いほうに合わせると坂の上側で頭がつかえて通れなくなるため）。

### 難易度の検証について

跳躍距離は `v·t`（t は落差を考慮した滞空時間）で決まります。設計時は次を機械的に確認しました。

- すべての穴が「その地点の速度での最大跳躍距離の 6割以下」に収まっていること
- **動作の切り替え**（跳ぶ→伏せる等）が、着地してから 0.25秒以上あとに来ること。
  高速域では1回の跳躍が 17m 進むので、跳んだ直後に別の動作を要求しない
- 敵は近づくと自分から寄ってくるため、**実際に出会う位置**で穴や障害物と重ならないこと
- 動作の間隔が 2.5秒以上空かないこと（空くと「だらっと」する）

Playwright + headless Chromium で自動プレイのボットを走らせ、**3回連続で完走**することを
確認しています（各 54.4秒 / 結晶 75〜77 / 無傷）。

## 気候（climate）の差し替え

見た目とパラメータは `CLIMATES` に分離してあります。`CLIMATE_ID` を変えるだけで、
空・霧・地面・氷・障害物・木・遠景・粒子・BGM の音階まで丸ごと入れ替わります。
プロトタイプの実装対象は `winter` ですが、構造の見本として `summer`（灼熱の海岸）の
データも入っていて、`CLIMATE_ID = 'summer'` にすれば通しで遊べます。

## 技術メモ

- **three.js r128（CDN）1本のみ。** テクスチャも音も手続き生成で、外部アセットはゼロ
- 地形・木・障害物は 110m 区画ごとに**1メッシュへ焼き込み**。傾斜した地面は 4m の小片に
  割って、面ごとに色を持たせた自前のジオメトリビルダ（`GB`）で組む
- **ドローコール 30 前後 / 三角形 4k**。結晶は InstancedMesh、敵は近づいたときだけ生成
- 遠景の山は3層の視差スクロール
- カメラは**画面の横幅が 33〜38m になる距離**を毎フレーム計算する。端末のアスペクト比が
  変わっても「先が見える距離」が変わらないので、スマホでも同じ難易度になる
- 接地判定は「足元にある一番高い面」を探す方式。上り坂に登る余裕と下り坂に貼り付く余裕を
  速度から決めているので、坂でも跳ねずに追従する
- 落下死は絶対座標ではなく**直前に立っていた高さから 12m**（コース全体が下っていくため）
- 音は WebAudio 合成。スマホは縦向きを検出すると回転を促してポーズする
