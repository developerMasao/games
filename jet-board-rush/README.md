# JET BOARD RUSH — FROST RIDGE

ジェット付きボードで雪山を滑り降りる、オートスクロールの横スクロールアクション。
参照は『ロックマン8』のスノーボード面と、スーパーマリオの自動スクロール面。
**1プレイ約63秒。** 依存は CDN の three.js だけで、`index.html` 単体で動きます。
**スマホ（横向き）対応。**

## 敵と展開（v5）

ジャンプを邪魔する敵を2種類足し、最後を「雪崩から逃げて大峡谷を跳ぶ」大詰めにしました。
どれもコースの台本（`ents`）で発動するので、位置を変えるだけで組み替えられます。

### 展開の流れ

| 区間 | 起きること | 緩急 |
| --- | --- | --- |
| 波1 | **ライバル**が奥の車線から追い抜き、飛び石を先に跳んで見せて去る（顔見せ・無害） | 予告 |
| 波2 | **カラス**が上空に居座り、後半に**煙玉**を2発落とす | 急：目隠し |
| 波4 | ジャンプ台の大穴を跳んだ直後から、**ライバルとの一騎打ち** | 急：対決 |
| 落ち着き | 何も来ない。下り坂に入ると**山が鳴り始め**、上から雪の塊が崩れ落ちてくる | 緩：予兆 |
| 最終区間 | ゲートをくぐった瞬間に**雪崩**。ライバルも逃げてきて最後の嫌がらせ → 雪崩に飲まれる | 怒涛 |
| 大詰め | 踏み切り坂から**大峡谷**を跳ぶ。曲が途切れ、頂点で長いスロー、着地で全部が戻る。花火 | 解放 |

### カラスの煙幕（ジャンプの目隠し）

- 前方の上空に居座り、煙の区画の 30m 手前で煙玉を投げる。0.42秒で着弾して、区画全体が
  **墨色の煙**に包まれる（着弾点から波のように広がる）
- 煙の中の障害物は、**近づくまで見えない**。13m を切ると輪郭だけが光る
  （跳ぶものは橙、伏せるものは水色の枠）。反応できる時間は普段の半分以下になる
- 自機のまわりだけは噴射で煙が吹き払われる（すぐ目の前は見える）

### ライバル（並走して邪魔してくる）

黒と紫のボード乗り。普段は**奥の車線**を並走していて（当たらない）、合図の音と一緒に
手前の車線へ割り込んできます。

| 動き | 何をしてくるか | 対処 |
| --- | --- | --- |
| block | 前に割り込んで減速し、道をふさぐ | **跳んで踏む**（+500、転げて一度下がる）/ 当たるとミス |
| hover | 頭の上に張りつく（赤い光の柱が警告） | **跳ぶと当たる**。上に結晶を並べて誘惑してある |
| drop | 前を飛びながら**氷の機雷**を落とす | 跳ぶ。2個は1回のジャンプで越せる間隔 |
| doom | 失速して雪崩に飲まれる | （見るだけ） |

公平さのための決まり：頭上に被さってきたとき空中にいた場合は当たらない／機雷は 7m より
近くでは落とさない／踏んだ跳ね返りの先に穴を置かない（踏んでから次の穴まで 9.5m 以上）。

### 雪崩（最終区間）

- ゲート通過と同時に背後の山が崩れ、1.4秒で画面の左端まで迫る。以後は**勢いを保っていれば
  左端で追ってくるだけ**、ブレーキで遅れると追いつかれてミス
- 雪崩は基準速度より少し速く、坂では自分と同じように速さが変わる。大詰めの坂では追いつかない
- 見た目は、泡立つ縁を持った雪の壁＋大きな雪煙＋前へ飛び散る雪の塊。近いほど画面左が白く飲まれ、
  地鳴りが大きくなる
- 大峡谷に落ちて止まる

### 大詰め

- 踏み切り坂に入ると画面の上下に帯が入る（映画の画面比）。カメラが引く
- 踏み切ると**曲が消える**。頂点で 0.8秒の深いスロー、自動の宙返り
- 着地で曲・重低音・和音が一気に戻り、雪煙の輪と光。ゴールでは花火
- 穴はすべてクレバスになった（奥の氷壁・崖・つららが下の闇まで続く）

## 見た目と体験（v4）

### 時刻がコースの緩急と一緒に進む

空・霧・太陽・環境光・遠景の色を、進行度で補間する時刻表（`ATMOS`）を持っています。
絵の変化が、そのままコースの山場を告げる作りです。

| 進行度 | 時刻 | 区間 |
| --- | --- | --- |
| 0 – 40% | 昼。青い空、白い雪 | 本編 |
| 57% | **黄金時間**。桃色の雪、長い影、雪面のきらめき | 落ち着き（空中レール） |
| 68% | **日没**。太陽が稜線に沈む | 58m の大下り坂 |
| 74% – | **夜とオーロラ**。星・月・灯籠 | 最終区間。ゲート通過でオーロラが燃え上がる |

空はシェーダーで描いた球（グラデーション・太陽の円盤と光冠・星・月・オーロラの幕）です。

### 描画

- **ポスト処理**：明部抽出 → 1/4 解像度で2段ぼかし → 合成（ブルーム・色調・周辺減光・
  速度に応じた放射ブラー・勢いに応じた色収差）
- シーンは少し暗く描いて合成で戻す（`EXPO`）。真っ白な雪は光らず、**太陽・オーロラ・結晶・
  炎・灯籠・雪のきらめきだけがブルームする**
- **影**：太陽（夜は月）からプレイヤーの周り 68×44m だけを落とす。黄金時間は影が長く伸びる
- **材質**：雪面のきらめき（上向きの白い面だけ、視点で瞬く）、氷の縁のフレネル光（夜は青く）
- **粒子**：1粒ごとに大きさ・透明度・色を持つ丸いスプライト。降雪は遠・中・近の3層で、
  近い雪は大きくぼける。雪煙は膨らんで消え、噴射炎・金色の尾・着地の輪・取得の弾け・ゲートの光

### 画質（自動）

| | 内容 | 既定 |
| --- | --- | --- |
| LOW | ポスト処理なし・影なし・頂点ライティング | 重い端末で自動的にここまで下がる |
| MED | ブルーム・影 1024・解像度 ×1.25・MSAA 2 | スマホ |
| HIGH | 上に加えて放射ブラー・色収差・影 2048・解像度 ×1.5・MSAA 4 | PC |

**60fps を割り続けたら自動で軽くします。** 1.5秒平均で 19ms（約52fps）を超えるたびに、
まず解像度を 12.5% ずつ 75% まで下げ（見た目はほぼ変わらない）、それでも足りなければ
画質を1段下げます。`G` キーで手動切替（切り替えたら自動調整は止まる）。
描画負荷は LOW で約30ドローコール・9k 三角形、MED/HIGH で約45ドローコール（影と
ポスト処理の6パス込み）・15k 三角形です。初回のカクつきを避けるため、タイトル画面で
シェーダー（隠れている演出のぶんも）を先にコンパイルします。

#### 重さの対策（v5.1）

重さの正体は、半透明の重ね塗り（オーバードロー）でした。1フレームに画面何枚ぶんを
塗っているかを場面ごとに測って削っています。

| 場面 | 前 | 後 | やったこと |
| --- | --- | --- | --- |
| 雪崩 | 画面 16 枚ぶん | **約 1 枚** | 雪煙を 110→24 個/秒に減らし小さく。量感は1枚の「雪の壁」で出す |
| 大峡谷 | 13 枚 | 0.7 枚 | 同上 |
| 煙幕 | 2.8 枚 | 2.5 枚（スマホは約半分） | 重ねる層を 3→2（スマホは1層を大きく） |

ほかに、飛び散る雪の塊の影をやめる（影の描画 10 回減）、何も出ていない煙の描画と
転送を止める、解像度の上限を下げる（HIGH 1.75→1.5、MED 1.35→1.25）。

### 手応え

- **ヒットストップ**（ミス 0.14秒・踏みつけ 0.07秒）、**スロー**（大ジャンプの頂点・ゲート・ゴール）
- ジャンプ台で大きく飛ぶと**自動で宙返り**。着地までに回り切れば FLIP +150
- 着地で体が沈む（ばね）、空中では脚をたたむ、高速域でボードが細かく震える
- **結晶を続けて取ると音程が上がっていく**（最大1オクターブ）。数字も跳ねる
- カメラは空中で引き、下り坂では少し傾いて坂を実際より急に見せる
- 対応端末では振動（ミス・大きな着地・ニアミス・ゲート）

### 音

コンプレッサと生成したリバーブのミックスバスに、区間で展開する曲を載せています。

| 区間 | 曲 |
| --- | --- |
| 本編 | キック・スネア・ハット・ベース（キックでへこむ）・アルペジオ |
| 落ち着き | ドラムが抜けて、パッドとアルペジオだけになる |
| 大下り坂 | だんだん細かくなるスネアロールとノイズの上昇音。テンポが上がる |
| 最終区間 | 4つ打ち・リード・テンポ 140 で全部入り |

効果音も作り直しました（布が裂ける被弾音、ジェットの轟音、ゲートのクラッシュなど）。

### 繰り返し遊ぶ理由

- **ゴースト**：一番速くクリアした走りを 20Hz で記録し、半透明のライダーとして並走させる。
  距離バーにも位置が出る
- **区間タイム**：最終ゲートで、ベストとの差（−0.84 など）を緑／赤で出す
- **リザルト**：行が順に出てスコアが数え上がり、最後に**ランク（S/A/B/C/D）の判子**が押される。
  ベストタイムとの差も出る
- スタートはカメラが引きから寄って **GO!**。`R` でいつでもやり直し
- 距離バーに「落ち着き区間」と「最終ゲート」の目印

### 背景の見せ場

出だしの針葉樹の森 → 氷結区間の光る氷晶 → ジャンプ台の奥の凍った滝 → 最終区間の両脇に並ぶ灯籠
（地面に光だまりが落ちる）。

### 直した不具合

手で組んだ地形の面（崖の断面・土手・氷の縁）の頂点の並びが逆で、**手前の崖が裏面として
消え、奥の壁の内側が見えていました**。今まで崖が紺一色に見えていたのはこのためです。
影を入れたことで、プレイヤーの影が「手前の崖」に落ちて発覚しました。

## 遊び方

プレイヤーは勝手に右へ進み続けます。できるのは **跳ぶ・伏せる・減速する** の3つだけ。

| | PC | スマホ |
| --- | --- | --- |
| ジャンプ | `↑` / `W` / `Space`（長く押すほど高い） | 画面右側をタップ（長押しで高く） |
| しゃがみ | `↓` / `S` | 押したまま下へスワイプ |
| 減速（後ろ向き） | `←` / `A` | 画面左端を押し続ける |
| ポーズ / 音 / 画質 / やり直し | `ESC` / `M` / `G` / `R` | 右下の ♪ |

ゲームパッドも使えます（A ボタン=ジャンプ、十字キー下=しゃがみ、左=減速）。

**画面の説明は最小限**です。タイトル画面では AI が自動でコースを走っていて、操作は最初の
8秒が教えます。スタート直後の3秒は結晶だけで何も来ず、そのあと
伏せるしかないアーチ → 跳ぶしかない穴 → 跳ぶ柱、の順に1つずつ出てきます。結晶はジャンプの
軌道上に並んでいるので、取ろうとすると自然に正しい跳び方になります。
一度クリアするとヒント表示は出なくなります。

## 設計：溜めてから、最後に放つ

コース全体が「**落ち着き → 急加速 → 怒涛**」の一本の線になるように組んであります。

| 区間 | 時間 | 速度 | 内容 |
| --- | --- | --- | --- |
| 導入 | 0-7秒 | 13 m/s | 8秒で3つの操作を教える |
| 波1 | 7-16秒 | 14-15 | **下って加速** → 飛び石3連（ライバルの顔見せ） |
| 波2 | 16-24秒 | 16 | くぐり連打 → **カラスの煙幕** |
| 波3 | 24-33秒 | 17-20 | **氷結ゾーン**。ブレーキが効かないまま密集地帯へ |
| 波4 | 33-43秒 | 13-17 | **ジャンプ台**。大穴を跳んで**ライバルと一騎打ち** |
| **落ち着き** | **43-48秒** | **17** | **障害物が減る。代わりに空中の「落ちる道」** |
| **急加速** | **48-50秒** | **17 → 25** | **58m の下り坂。2秒で +8 m/s。山が鳴り始める** |
| **怒涛** | **50-59秒** | **21-24 を維持** | **雪崩に追われながら、最高速のまま密度が最大になる** |
| **大詰め** | **59-63秒** | 19-22 | **大峡谷を跳ぶ。曲が消え、頂点でスロー、着地で全部戻る** |

10秒ごとの動作数は **7, 7, 9, 6, 4, 8** — 落ち着き区間で意図的に 4 まで落とし、
最終区間で 8 に跳ね上げています。動作の間隔は中央値 1.27秒。

（前の版は 88秒で、冒頭20秒に動作が3回しかなく、最大 6.9秒なにも来ない区間がありました）

## 勢い（momentum）：坂で稼いだ速度は捨てない

**これがこのゲームの背骨です。** 坂で得た速度が1秒で消えてしまうと、
どれだけ坂を置いても「速くなった感じ」が残りません。そこで速度を2つに分けています。

```
実際の速度 ＝ 基準カーブ（進行度で決まる） × 坂にいるあいだの倍率 ＋ 勢い
```

**勢い**は下り坂で貯まり、上り坂で減り、**平地では毎秒 0.3 しか減りません**（上限 +7.0）。
つまり一度上げた速度はコースの終わりまでほぼ保たれます。

減らすのは3つだけです。

| | 効果 |
| --- | --- |
| **ブレーキ** | 毎秒 3.2 減る。**減速は「稼いだ勢いを捨てる」行為**になる |
| 上り坂 | 傾きに応じて減る（登り切ったあとの踏み切りが見せ場になる） |

速度計は勢いが乗っているあいだ金色に光ります。

## 地形：坂とジャンプ台

地形は「平ら」だけでなく**傾斜**を持ちます。坂にいるあいだは速度が最大 1.30 倍まで伸び、
上り坂では 0.80 倍まで削れます（これは坂を離れると戻る、その場の効果）。

**上り坂の終端はジャンプ台**になります。坂を離れる瞬間（＋その後 0.5秒）にジャンプすると、
坂の傾きと速度に応じた上向きの勢いが跳躍に上乗せされ、通常の倍近く飛びます（最大 +12 m/s）。
波4の大穴（12m）と、落ち着き区間の空中レールはこれを使います。
踏み切り場に平らな部分を作ってあるので、「どこで跳ぶか」が目で分かります。

## 落ちる道（空中レール）

落ち着き区間には、地面の 3.6m 上に**4枚の足場が連なるレール**があります。

- 踏み切り坂から跳ぶと乗れる。**結晶が弧を描いて並んでいて、それがそのまま跳び方の見本**になる
- レールの上は結晶だらけ。継ぎ目は小さく跳んで渡る
- **落ちても死にません。**下の道（安全だが柱が2本ある）に降りるだけ
- つまり「安全に流す」か「稼ぎに行って落ちるかもしれない」かを選べる区間

## 最終区間のゲート

怒涛パートの入口に、くぐるだけの**巨大な氷のゲート**が立っています。
通過すると画面が白く光り、音が鳴り、BGM が一段上がります。当たり判定はありません。
「ここから最後」を文字なしで伝えるための仕掛けです。

基準の速度カーブは控えめにしてあります（`STAGES[0].speed`）。最高速は坂と勢いで作ります。

| 進行度 | 0% | 30% | 50% | 68% | 87% | 100% |
| --- | --- | --- | --- | --- | --- | --- |
| 基準速度 | 13.0 m/s | 15.8 | 16.6 | 17.0 | 19.2 | 20.6 |

## 体感速度

速度は m/s ではなく画面の流れ方で感じるものなので、速度に連動させています。

- **画角（FOV 34°→41°）とカメラ距離**が速度で広がる
- **手前を小物が流れる**（画面の下端をかすめる氷片）。速度感の大半はこれ
- 高速域で**流線**が走り、雪煙が増え、カメラが微振動する
- **着地でカメラが沈む**（落下速度に比例）
- 風の音程・ジェット音・**BGM のテンポ**（最大 +22%）が速度に連動
- カメラは **20m 先の地形の高さ**を見て構えるので、落ちる前に落ちる先が見える

## ニアミス

障害物を**すれすれ（0.62m 以内）で通過**すると火花が散って +40点。穴の縁ぎりぎりに
着地したときも入ります。**2秒以内に続けて決めると倍率が上がり**（最大 ×5）、
密度の高い最終区間ほど大きく稼げます。
危ない通り方が損ではなく得になるので、自分から際どく攻める動機になります。

## ミス：1回当たったら終わり

障害物・敵・機雷・ライバル・雪崩のどれかに当たるか、穴に落ちたら**その場でミス**です。
残機も体力もありません。1プレイが約60秒なので、ミスしたら `R`（タップ）ですぐ最初から。
当たった瞬間は一瞬止まって火花が出るので、何に当たったかは分かります。

（以前は1回目で服が脱げてパンツ一丁になり、2回目でミスでした。1ミスで終わる設計に変更し、
服の回復アイテムもコースから外しました。`wear` は部品として残っていますが未使用です）

## コースの作り方（データ構造）

コースは**部品（CHUNK）を並べただけ**です。`CHUNKS` に部品を足して `STAGES[].seq` に
名前を並べれば、新しいコースができます。

地形は `terrain`（**長さと高低差の鎖**）で持ちます。`['gap', 幅, 落差]` が穴です。

```js
w4_launch: {
  len:173,
  //        平ら   上り坂    踏み切り   大穴(先が3m下)  下り     平ら   穴    平ら
  terrain:[[20,0],[16,4.5],[6,0],['gap',12,-3],[22,-2],[24,0],['gap',9],[16,0],[48,0]],
  ents:[
    {t:'low',   x:14, w:4, y:1.30},        // くぐる（地面から 1.30m）
    {t:'block', x:40, h:1.8, w:1.6},       // 跳ぶ（上面には乗れる）
    {t:'plat',  x:20, w:7, y:0.8},         // 飛び石の足場
    {t:'ice',   x:18, w:92},               // 氷結ゾーン
    {t:'enemy', x:72, kind:'slider'},      // slider=地上（跳ぶ）/ flyer=頭の高さ（伏せる）
    {t:'coin',  x:44, y:3.4},              // 大穴の上に置くと飛距離の目印になる
    {t:'coins', x:6, y:0.65, n:3, dx:2.6, arc:1.2},
    {t:'sign',  x:4}, {t:'hint', x:6, icon:'brake'}, {t:'goal', x:30}
  ]}
```

演出と嫌がらせも同じ `ents` に書きます。**x はプレイヤーがそこを過ぎたら発動する位置**です。

```js
{t:'crow',  x:6,   a:'enter'},            // カラス登場（'leave' で去る）
{t:'smoke', x:62,  w:24},                 // 煙の区画（カラスがいれば手前 30m で煙玉を落とす）
{t:'rv',    x:30,  a:'enter'},            // ライバル登場（奥の車線を並走）
{t:'rv',    x:56,  a:'block', at:82},     // at の位置でプレイヤーと鉢合わせるよう減速してくる
{t:'rv',    x:119, a:'hover', to:132},    // to まで頭上に張りつく
{t:'rv',    x:133, a:'drop'},             // 前を飛んで、台本にある機雷を落としていく
{t:'mine',  x:150},                       // 機雷の位置（ライバルが通るまで存在しない）
{t:'rv',    x:160, a:'leave'},            // 'doom' は雪崩に飲まれる
{t:'aval',  x:120, a:'rumble'},           // 山鳴り（'go' で雪崩、'stop' でそこで止まる）
{t:'fin',   x:0}                          // 大詰めの演出開始
```

`compile()` がこれを絶対座標のワールドに展開します。`ents` の `y` は**その地点の地面からの高さ**
なので、坂の上でも同じ書き方でいいです（障害物は幅の中で**一番高い地面**を基準に置かれます。
低いほうに合わせると坂の上側で頭がつかえて通れなくなるため）。

### 難易度の検証について

跳躍距離は `v·t`（t は落差を考慮した滞空時間）で決まります。設計時は次を機械的に確認しました。

- すべての穴が「その地点の速度での最大跳躍距離の 6割以下」に収まっていること
- **動作の切り替え**（跳ぶ→伏せる等）が、着地してから 0.25秒以上あとに来ること。
  高速域では1回の跳躍が 17m 進むので、跳んだ直後に別の動作を要求しない
- 敵は近づくと自分から寄ってくるため、**実際に出会う位置**で穴や障害物と重ならないこと
- 動作の間隔が 2.5秒以上空かないこと（空くと「だらっと」する）

Playwright + headless Chromium で自動プレイのボットを走らせ、**3回連続で完走**することを
確認しています（各 60.3秒 / 結晶 90 / 無傷）。動作の間隔の検査には、
**実プレイで記録した速度（勢い込み）** を使っています。基準カーブだけで見ると
終盤を 17 m/s と誤認して、実際には 22 m/s で来る区間を安全だと判定してしまうためです。

## 気候（climate）の差し替え

見た目とパラメータは `CLIMATES` に分離してあります。`CLIMATE_ID` を変えるだけで、
空・霧・地面・氷・障害物・木・遠景・粒子・BGM の音階まで丸ごと入れ替わります。
プロトタイプの実装対象は `winter` ですが、構造の見本として `summer`（灼熱の海岸）の
データも入っていて、`CLIMATE_ID = 'summer'` にすれば通しで遊べます。

## 技術メモ

- **three.js r128（CDN）1本のみ。** テクスチャも音も手続き生成で、外部アセットはゼロ
- 地形・木・障害物は 110m 区画ごとに**1メッシュへ焼き込み**。傾斜した地面は 4m の小片に
  割って、面ごとに色を持たせた自前のジオメトリビルダ（`GB`）で組む
- **ドローコール 30 前後 / 三角形 4k**。結晶は InstancedMesh、敵は近づいたときだけ生成
- 遠景の山は3層の視差スクロール。**縦方向にも視差を掛けてある**（コースが 28m 下るので、
  掛けないと山が画面の上へ抜けていく）
- カメラは**画面の横幅が 33〜38m になる距離**を毎フレーム計算する。端末のアスペクト比が
  変わっても「先が見える距離」が変わらないので、スマホでも同じ難易度になる
- 接地判定は「足元にある一番高い面」を探す方式。上り坂に登る余裕と下り坂に貼り付く余裕を
  速度から決めているので、坂でも跳ねずに追従する
- 落下死は絶対座標ではなく**直前に立っていた高さから 12m**（コース全体が下っていくため）
- 音は WebAudio 合成。スマホは縦向きを検出すると回転を促してポーズする
