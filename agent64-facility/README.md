# AGENT 64 — THE VAULT

厳重に警備された施設に潜入し、資料を奪って脱出する一人称アクション。
参照は『ゴールデンアイ007』『メタルギアソリッド』『ヒットマン』。
依存は CDN の three.js だけで、`index.html` 単体で動きます。

## 構成 — 静と動の二部構成

**行きは静かに、帰りは撃ち合い。** 資料に触れた瞬間が切り替えスイッチになります。

1. **潜入フェーズ** — 警備隊長を探してカードキーを奪う。麻酔銃とサイレンサー付き PP7、
   背後からの無音制圧。騒がないほど楽になる
2. **確保** — 保管庫の資料を取る。**この瞬間、施設が全力で起きる**（点呼できない警報が鳴りっぱなしになる）
3. **逃走フェーズ** — 増援が入口から途切れず流入。武器を持ち替えて撃ち抜けるか、走り抜けるか

先に**無線手2名**を潰しておくと、逃走時の増援到着が約1.9倍遅くなります。潜入中の下準備が
そのまま逃走の難易度になる、という設計です。

## 難易度

| | 増援の上限（初期15名込み） | 湧く間隔 | 敵の体力 | 命中率 |

| **1 AGENT** | 23人 | 10秒 | 100 | 0.46 |

## ミッション目標

- **A**: 警備隊長からカードキーを奪う（倒すと落とす。麻酔で眠らせても落とす）
- **B**: **地下**の保管庫まで降りて資料を確保する
- **C**: 脱出する
- 任意: 無線手 2 名を排除しておくと、逃走時の増援が遅れる

## 人質

警報が鳴っている間、**人質の危険度メーターが上昇**する。無線手が生きていると上昇は約2.3倍。
振り切られると人質は殺され、その時点で任務失敗。警報が止めば徐々に下がる。
解放後はプレイヤーを追って走り、脱出口まで連れて行けばクリア。

## 指示役（MOTHER）

無線で状況を送ってくる。作戦開始、無線手の排除、警報の性質（全域か局所か）、
標的の逃走、人質の確保 — 状況が変わるたびに声が入る。画面左下に通信ログとして出る。
腕時計（TAB）には**組織図**があり、役割ごとの残存数と通信状態が見える。

## 高さのある地形

セルごとに床の高さを持ち、**スロープ（傾斜セル）で上下に移動する**。
真上に部屋を重ねる完全な多層構造ではないが、平面上に別階層を配置することで
「外 → 建物 → 地下 → 地上」の動線が成立する。

- 地下保管庫は **y = -3.6m**（ちょうど一層ぶん下）
- 中央通路（z9）の施錠扉から、2セル（8m）の傾斜路で降りる。傾斜は約24度
- カードキーで開くのはこの扉のみ。**資料は地下にある**
- 段差 1.5m 以上は壁として扱われるため、崖から落ちることはない
- プレイヤーも警備兵も床の高さに追従し、視線・射線・弾道もローカルな床と天井を基準に判定する

## ステージ構成 — 中央保管区画（42x34）

自動生成をやめ、**意図を持って手で設計**している。合言葉は「視線が通らない」。

### 空間：廊下は1マス幅、部屋は小さく、扉は49枚

以前の版は生成器の不具合で部屋同士の壁が消え、翼ごとに 10x13 の大広間になっていた。
現在は本家 Facility と同じ作りに戻している。

- 廊下はすべて **1マス幅（4m）**。部屋は 3〜5 マス角で、出入口は扉 1 枚
- **廊下の途中にも扉**を置いた（翼の境目・リング廊下の四隅）。閉じた扉は視線も銃弾も通さないので、
  36 マスの直線廊下が 10〜13 マスに切れる
- 屋外の敷地にもタンク列を置いて、160m の見通しを切った
- 実測（直線で見通せる長さの平均、全開放セル・4方向）: **33.4m → 14.6m**。
  40m 以上の見通しを持つセルは 308 → 64（残りはほぼ屋外）

```
       [北棟：研究室 研究室 更衣室 管制室 標本庫 倉庫]   ← 扉つきの小部屋が並ぶ
   ┌─────┬───── 北リング廊下 ─────┬─────┐
 西│武器庫│ ┌──── 沈んだ中央区画 ────┐ │事務室│東
 廊│ 手洗 │ │ 小部屋 ┌──────┐ 小部屋 │ │警備室│廊
 下│ 倉庫 │ │ (配管) │ 保管庫 │        │ │研究室│下
   │      │ │ 小部屋 └──扉───┘ 小部屋 │ │      │
   └─────┴───── 南リング廊下 ─────┴─────┘
       [南棟：武器庫 食堂 事務室 更衣室] → 門2つ → [敷地：脱出口]
```

- **出口は二つ。** 南の門（近いが増援の湧き口）か、入ってきた配管（遠く、這うので遅いが誰もいない）。
  資料を取った瞬間に MOTHER が両方を提示するので、どちらで帰るかは取る前から考えておくことになる。
  配管は資料を持っていないと出口として成立しない
- 中央区画は一段低く（-3.6m）壁で囲われ、降りられるのは南北2本の傾斜路だけ。
  内部は保管庫を囲む **8つの小部屋** に仕切られ、扉で繋がる
- **保管庫への入り方が2通り**: 南側の施錠扉（隊長のカードが必要）と、
  西側の閉じた小部屋から入る通気ダクト（しゃがみ限定・**警備兵は通れない**）

### 緩急：安全地帯から始まる

ゲームは**通気配管の中**から始まる。しゃがんで這って進むと手洗いに出る。
ここまで敵は一人もいない。**扉を開けた瞬間から敵地**になる（45秒放置しても無傷・警戒ゼロを確認）。

配置密度も入口から遠いほど濃い。警備兵は全15名。

| 西棟（開始地点側） | 廊下に1名 | なし |
| 北棟 | 3名 | 1基（管制室） |

### 逃走時の警報

資料を取ると警報が鳴るが、**全員が自分の位置に殺到する作りではない**。

- 中央区画の中にいた者（22m以内）だけが保管庫へ走る
- それ以外は「警戒度が上がって保管庫の方を向く」だけで持ち場を離れない
- **狩りは増援の仕事。** 屋外の敷地とその出入口から投入され、盗まれた地点へ向かう。
  見つからなければ湧き口方向へ戻りながら散開する

実測（資料確保後、保管庫で待機）:

| 経過 | 追ってくる既存兵 | 増援 | 30m以内の敵 |
| --- | --- | --- | --- |
| 15秒 | 3 | 2 | 2 |
| 45秒 | 3 | 5 | 5 |
| 60秒 | 3 | 6 | 6 |

以前は 9 秒で 13 名が保管庫に向かっていた。

## 旧・ステージ構成

本家 Facility に寄せて、**1マス幅（4m）の通路と小部屋の集合**に再設計した。開けた大部屋は無い。

- 縦5本・横4本の通路がグリッドを作り、その間を 5x3 / 4x2 程度の小部屋が埋める。
- **扉が30枚**。部屋の出入口に加え、長い通路の途中にも置いてあるので、
  自動で開くまで先が見えない＝視線が通らない。
- 監視カメラ4基はすべて通路を見張る位置にある。
- 全352セルが連結済み（生成時に到達性を機械検証）。

警備兵はグリッド上のダイクストラ経路探索で移動するので、迷路でも詰まらない（CPUデモと同じ探索を共有）。

## 潜入（ステルス）の仕組み

開始時点では**誰にも気づかれていない**。見つかるまでは静かに進める。

- **視界**: 警備兵は前方 ±46°（交戦中は ±72°）しか見ていない。**真後ろは完全な死角**。
- **明るさ**: 暗い区画ほど見つかりにくい（天井灯からの距離で焼き込み済み）。しゃがめば視認距離はさらに 38% 減。
- **音**: しゃがみ移動＝無音 / 歩き＝半径 11 / ダッシュ＝半径 21。サイレンサー付き PP7 は半径 9 だが、KF7 は半径 46 で撃った瞬間に一帯が動く。
- **警戒段階**: 巡回 → `?`（不審・その場で確認）→ 現場へ移動 → `!`（発見・交戦）。
  視界から 4.5 秒消えると捜索に切り替わり、見失えば巡回へ戻る。
- **無音制圧**: 気づかれていない警備兵の**背後 2.9m 以内**で `E`。声を上げずに倒せる。
- **死体**: 巡回中の警備兵が見つけると不審状態になり、周囲を呼ぶ。
- **警報**: 監視カメラに 0.9 秒映ると全員が位置を共有（22 秒）。カメラを先に潰すのが定石。

## CPU デモ（自動プレイ）

タイトル画面または game 中に `P`。AI がミッションを最後まで遂行するのを観られる。
もう一度 `P` で手動に戻る（キー状態はクリアされる）。

スクリプト再生ではなく、**プレイヤーと同じ入力**（視点・WASD・射撃・E）を AI が叩いている。

- 敵の視線コーン・監視カメラの視界を**コストとして重み付けした経路探索**（ダイクストラ）で、見つかりにくい道を選ぶ。
- 次の一歩が誰かの視界に入るなら、その場でしゃがんで巡回が過ぎるのを最大4秒待つ。
- 気づかれかけたら、視線が切れるセルを探して隠れる。
- 背後を取れる敵がいれば忍び寄って無音制圧。
- 見つかったら交戦。近距離では頭を狙い、劣勢（体力52%未満／視界内に3人以上）なら
  遮蔽物の裏へ後退し、必要ならKF7に持ち替える。
- 体力が減っていればボディアーマーを取りに行く。

検証: 連続4回すべてミッション達成（1:43〜3:02、無音制圧3〜5件、うち1回は無傷でクリア）。

### 現在の行動（配管開始・二つの出口に対応）

1. 無線兵を優先して眠らせる／倒す（増援の速さに直結）
2. 資料へ。カードが無ければ西側の通気ダクトから保管庫へ這って入る
3. 出口を選ぶ。南の門と配管の両方へ経路探索し、配管が明確に短いときだけ配管を使う
4. 交戦は実弾（PP7 / 2人以上なら KF7）。麻酔銃で撃ち合いはしない
5. 配管の中では脅威を無視して這い続ける（横移動も退避もできないため）
6. 追い詰められたら退避せず撃ち返す

実測: 2回連続で任務完了（114秒 / 131秒、HP 93 / 100、無力化6名）。
それまで区画内で必ず死んでいた原因は、一段低い区画で敵の頭を「地面から2.0m」で狙っていたこと（3.6m上を撃っていた）と、
至近距離で横に動きながら照準の許容誤差に入れなかったこと。

## 手応え（ゲームフィール）

GoldenEye の代名詞である**部位別の被弾リアクション**を実装している。

- **当たり判定は7部位**（頭・胸・腹・左右腕・左右脚）。倍率は頭 3.2 / 腹 1.15 / 胴 1.0 / 腕 0.55 / 脚 0.5。
- **部位ごとに違う反応**: 腹＝体をくの字に折る / 脚＝膝が折れて崩れ、以後 4.5 秒足を引きずり移動速度 45% 減 /
  腕＝腕が跳ね上がり銃を下げ、1.4 秒撃てない（利き腕なら射撃中断も長い）/ 胸＝仰け反る / 頭＝首が跳ねる。
  被弾で射撃が中断され、着弾方向へノックバックする。
- **死亡モーションは5種＋制圧**: 頭＝糸が切れたように崩落 / 脚・腹＝膝をついてから前のめり /
  背後から＝body が反り返って腕が上がる / 腕＝独楽のように回って倒れる / 正面＝仰向けに倒れる。
  倒れる際に慣性で少し滑り、床に血だまりが残る。
- **敵の戦闘挙動**: 弾倉は30発。撃ち切ると遮蔽物の裏へ回り込んで 2.3 秒かけて弾倉交換する（銃を下ろし
  空いた手をマガジンへ運ぶ動作が見える）。手負い（体力62%未満）でも遮蔽に入り、1.4秒で出て押し返す。
  発見・見失い・リロード・遮蔽への移動で、それぞれ違う掛け声を出す。
- **被弾フィードバック**: どの方向から撃たれたかを示す赤いインジケータ、被弾時のカメラキック。
- **死亡カメラ**: 1.5 秒かけて視点が床へ落ちながら傾き、画面が赤く沈む。その間 HUD はフェードアウトする。
- **武器の手触り**: 視点回転に銃が遅れて追従する慣性、発砲の跳ね上がり、薬莢の排出、
  リロード時の銃の沈み込みと回転、壁に残る弾痕（面の交点に正確に配置、48個をプール再利用）。
- ダッシュ時は FOV が広がり、頭の揺れとロール角が増える。

## 仕様メモ

- 警備兵 9 名がそれぞれ固有の巡回ルートを歩き、要所で立ち止まって周囲を見回す。
- 交戦時は接近・ストレイフ・バースト射撃。頭部ヒットは 3.2 倍ダメージ。
- ヘルス＋ボディアーマー（アーマーが 72% を肩代わり）。GoldenEye 風の二重アークHUD。
- 自動ドア（施錠ドアは目標達成で解錠）、柱・木箱・ドラム缶・ロッカーによる遮蔽と視線遮断。
- 部屋ごとに色調が異なり、配管・通気口・警告帯・床グレーチング・天井梁などで作り込み。
- 警備兵は膝関節付きのリグで、実際の移動速度からアニメーションを駆動（歩き→走りのストライド、前傾、腰の捻り、腕振り）。
  下半身は進行方向、上半身はプレイヤーの方を向く分離制御なので、走りながらこちらを狙う動きになる。
- テクスチャは 256x256 の手続き生成アトラス（壁パネル / コンクリート / 金属 / 木箱 / 警告帯 / グレーチング）を
  ニアレストフィルタで貼付。天井灯からの焼き込みライティングと壁際のコンタクトシャドウを頂点カラーで乗算。
- N64 風の演出: 1/3 解像度レンダリング＋ニアレスト拡大、濃いフォグ、ローポリ。
- 効果音・BGM はすべて WebAudio による合成（外部アセット・外部音源なし）。
- **BGM は状況で3層に変化する**: 潜伏中はベースとハイハットだけ、警戒されるとオフビートとアルペジオが乗り、
  発見・警報でスタブとリードが入る。0.8秒でクロスフェード。`M` でオン/オフ。
  （本家の曲は使えないので、あの系統のオリジナル進行を合成している）
- **描画の追加**: シャドウマップ（キャラと遮蔽物が床に影を落とす／光源はプレイヤー追従）、
  自前のポストプロセス1パス（ブルーム・カラーグレード・周辺減光・グレイン・被弾と警報の色被り）。
- 監視カメラは筐体を大型化し、**緑の走査ビーム**と点滅LED、旋回音を追加。発見時はビームが赤く明滅する。

## 最適化の記録

マップを 32x24 から 42x32 に拡張し、警備兵を10人から18人に増やしたとき、
フレーム時間が 1.5ms から **9.3ms** に悪化した。内訳を測ったところ:

| 項目 | 時間 |
| --- | --- |
| 警備兵18人のAI | 0.41 ms |
| 監視カメラ | 0.00 ms |
| プレイヤー | 0.04 ms |
| HUD | 0.09 ms |
| **描画** | **15.7 ms** |

原因はポリゴン数ではなく**シーン内のメッシュ数＝ドローコール**（1082個）。
その約半分が警備兵18人×25パーツだった。剛体パーツ単位でジオメトリを結合し、
1人あたり25→11メッシュに削減:

- メッシュ数 1082 → **588**
- 描画 15.7ms → **1.8ms**
- フレーム全体 9.3ms → **2.08ms**

経路探索も、セル数の2乗で重くなる線形探索から**バイナリヒープ付きA***に置き換えた
（角から角まで 0.187ms）。

## 描画負荷（実測 / Apple M2）

`G` キーで画質3段階を切替。左下に FPS・フレーム時間・ドローコール数が出る。

| 設定 | 内部解像度 | フレーム時間 | 換算 |
| --- | --- | --- | --- |
| 低（N64風・既定） | 640x360 | **1.42 ms** | 700fps 相当 |
| 中 | 960x540 | 1.43 ms | 700fps 相当 |
| 高（等倍） | 1920x1080 | **1.49 ms** | 670fps 相当 |
| 参考 | 2560x1440 | 1.47 ms | 680fps 相当 |
| 高・影なし | 1920x1080 | 0.74 ms | 1350fps 相当 |

**解像度を9倍にしてもコストはほぼ変わらない**（1.42→1.49ms）。ピクセル数ではなく
フレームあたりの固定コストで律速しているため。60fps の予算 16.7ms に対して使用は約9%、
つまり**11倍の余裕がある**。

内訳で一番重いのは**影のパス**（1080pで約0.75ms＝フレームの半分）。シーンをもう一度
描き直すため。光源を増やすとここが線形に増えるので、影を落とす光源は1つに絞ってある。

重くなる要因は解像度でもポリゴン数でもなく、
**①影を落とす光源の数 ②ドローコール数（現在約300、数千で問題化） ③全画面の半透明**。

## 既知の仕様

- ポインタロックが使えない環境（ブラウザ設定や埋め込み表示）では自動的に簡易操作へフォールバックする。
- トラックパッドの短いタップでも必ず 1 発撃てるよう、クリックはフレームをまたいでラッチしている。
